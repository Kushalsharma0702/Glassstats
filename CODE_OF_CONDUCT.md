# Code of Conduct

Everyone contributing to GlassStats should be able to participate without harassment or intimidation. Discuss the work, assume good faith where reasonable, and respect other people's time, privacy, and boundaries. Harassment, threats, discriminatory language, disclosure of private information, and sustained disruption are unacceptable.

These expectations apply to repository issues, pull requests, discussions, and other project spaces. Report concerns privately to a repository maintainer through their published contact information. Maintainers may remove content, restrict participation, or remove participants as appropriate. Maintainers should handle reports discreetly and avoid unnecessary disclosure.
