# Changelog

## 0.2.0

- Made clear glass the default and removed the dashboard’s native title bar and gradient fills.
- Added dashboard card and shortcut controls, live local Docker monitoring, and confirmed single or bulk port-close actions.
- Switched to wake-on-demand sampling and added a Low Power mode.

## 0.1.0

- Added the live native dashboard, resizable floating panel, configurable menu bar, and global dashboard shortcut.
- Added CPU, memory, network, storage, thermal pressure, GPU capabilities, and Neural Engine capability monitoring.
- Added process and local TCP/UDP inspectors with filtering, sorting, and socket copying.
- Added bounded chart history, opt-in SQLite storage, and six snapshot-based WidgetKit configurations.
- Added native app and Universal packaging, automated tests, and GitHub Actions CI configuration.
